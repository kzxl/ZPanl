# Project Rules: ZPanl ⚡🌐

## Identity & Architecture
- **Name**: ZPanl (Sovereign Linux Web Panel for Static Websites and PHP-FPM)
- **Role**: Lightweight, zero-dependency, single-binary Linux web control panel
- **Language**: Pure Rust (2021 edition)
- **Dependencies**: 100% sovereign ZeroRust foundation crates (`zero-sys`, `zero-fastcgi`, `zero-caddy`, `zero-vfs`, `zero-core`)
- **Target OS**: Linux (x86_64, aarch64), cross-compatible with Windows/macOS for development
- **Footprint**: < 10 MB RAM, sub-second startup, zero external runtime packages (embedded SPA Web UI)

## Security Boundaries
- All web root file operations MUST pass through `zero-vfs::JailSandbox`.
- All writes to web files MUST use `zero-vfs::AtomicPathBuilder` to prevent partial/corrupted writes.
- Never grant `0o777` permissions; strictly enforce `0o755` for directories and `0o644` for files.
- Configuration reload on Caddy MUST be atomic via Caddyfile generation or Caddy Admin API (`POST /load`).
